# PUP Santa Rosa — Student Desk (Visual Redesign)

A responsive single-page website/UI concept for the GEED 028 visual communication task. This redesign replaces search and category filters with direct task-based links and a simpler information hierarchy.

## Open the website

Open `index.html` in a current browser. No build step or installation is required. The PUP seal, campus photograph, and typefaces are loaded from their public online sources, so an internet connection is required for those visual assets. If the campus photograph cannot load, a local vector illustration is displayed instead.

## What changed in this redesign

- Removed the search bar and the Everything / Academic / Accounts filters.
- Removed generic system categories and kept student tasks that are supported by PUP's published campus pages.
- Replaced the old hero layout with a two-column editorial composition and a properly framed campus photograph.
- Changed the type pairing to DM Sans, DM Serif Display, and IBM Plex Mono.
- Added a clearer campus directory, source credits, an explicit unofficial-concept notice, and a mobile navigation menu.
- The website does not collect logins, passwords, student numbers, or any personal information.

## Main student services represented

1. Student Information System — official PUP student portal for class lists and grades.
2. Santa Rosa ARO — campus page for document request forms and status links.
3. Student ID application — campus-published page listing new, replacement, transfer, and lost-ID routes.
4. PUP SINTA — student support for questions and concerns, including admission, enrollment, and library processes.
5. PUP WebMail — Microsoft sign-in; campus WebMail setup/reset information remains on the campus page.
6. Facilities and equipment reservation — campus-published notice and procedure page.
7. CVASS — campus appointment scheduling page.

## Accuracy notes

The official PUP Santa Rosa website confirms campus identity, academic context, official emails, phone numbers, and address. The campus WordPress service directory currently links to the local ARO, ID, reservation, and CVASS pages. Some instructions are older (including the ID page dated 2021 and facilities notice dated 2024); the site deliberately directs students to verify current requirements with the campus rather than claiming every form or procedure is guaranteed current.

The website is a student-created visual communication concept and is not endorsed by PUP. It links to public sources but does not reproduce or host PUP's systems.

## Visual direction — Version 3

The design takes inspiration from the user's reference screenshot: a narrow dark-maroon identity strip, warm-white navigation, a dramatic burgundy gradient hero, oversized high-contrast sans-serif headline with gold italic serif emphasis, and an offset framed campus image with small editorial labels. The page content, service destinations, contact information, and interactions are retained from Version 2.
